## 一、概述

**NoteEverything** 是一个以"软件/游戏"为锚点的个人记录工具。核心场景：玩游戏后，将感想和游玩时长绑定到游戏条目上，形成以 App 为维度的记录体系。

与通用笔记软件的区别：NoteEverything 以"你在用什么软件"来组织信息，而非以时间或文件夹来组织。

### 一句话描述

> 绑定到每个 App/游戏的感想笔记 + 时长追踪工具。

## 三、核心数据模型

三个核心实体，以 Software 为锚点：

- **Software**（软件/游戏实体）：名称、平台、图标、分类
- **TimeRecord**（时长记录）：必须关联 Software，记录起止时间/时长
- **Note**（笔记/感想）：可选关联 Software，不关联时为自由随笔；支持图片、地点、时间戳

关键规则：
- TimeRecord 必须有 softwareId（时长总得有个对象）
- Note 的 softwareId 可为空（空 = 自由随笔）
- 两个表都通过 softwareId 查询，拉出一个软件的全部时长和笔记

## 四、页面结构

### 底部导航（三 Tab）

| Tab | 内容 |
|-----|------|
| 软件 | 软件列表，按分类分组，每项显示名称 + 今日时长 + 最近笔记 |
| 随笔 | 全部笔记时间轴，支持搜索，自由随笔和软件笔记混合展示 |
| 时长 | 今日/本周/本月统计，按软件排行，简易日历日视图 |

### 详情页（点击软件进入）

- 软件信息头部
- 时长记录区：手动录入起止时间，或内置计时器（开始→停止→保存）
- 该软件下所有笔记卡片

### 编辑页（新增/编辑笔记）

- 软件选择下拉（可选，不选 = 自由随笔）
- 正文编辑区
- 图片添加（拍照/相册）
- 时间戳（默认当前，可调整）

### FAB（浮动操作按钮）

- Tab = 软件 → 添加软件
- Tab = 随笔 → 新随笔
- Tab = 时长 → 开始计时

## 五、后续扩展（非 MVP）

以下功能已识别但不纳入首次开发：

1. **日历视图** — 日历形式展示每日动态，作为时长的增强视图
2. **剪切板备忘录** — 快速捕捉，拆分小窗口，可选与主应用联动
3. **Android UsageStats** — 自动检测手机 App 使用时长
4. **Steam API 集成** — 同步 Steam 游戏时长数据
5. **云端同步** — 多端数据同步（手机 ↔ PC）
6. **外部数据源连接** — 连接其他平台同步数据
7. **富媒体记录** — 插入地点、图片等信息（MVP 已支持基础图片）
8. **组件模块化拆分** — 功能模块可独立启用/禁用

## 六、技术架构（简要）

```
UI Layer (Compose) → ViewModel → UseCases → Repository → Room DB
```

- **UI**：Jetpack Compose + Material3
- **状态管理**：StateFlow（ViewModel → UI）
- **持久化**：Room（SQLite），DAO 直接做统计查询
- **架构模式**：MVVM + Repository 模式
- **无额外抽象**：不引入不必要的接口层
